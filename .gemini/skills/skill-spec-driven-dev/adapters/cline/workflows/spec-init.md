# /spec-init

Run the `init` capability of the `skill-spec-driven-dev` skill.

1. Read `<SKILL_PATH>/SKILL.md` and `<SKILL_PATH>/rules-core.md`.
2. Follow `<SKILL_PATH>/capabilities/init.md` exactly.
3. Prompt the user for the Jira ticket id and workspace path as the
   capability specifies. Default workspace: `.specs/<FEATURE_KEY>/`.
